# Reglas de Desarrollo de bubbabag-client

## Estilos y Diseño
- **Prohibido TailwindCSS**: No instalar ni usar clases de TailwindCSS.
- **Vanilla CSS y Clases Propias**: Todo el diseño se maqueta con clases semánticas propias en CSS puro (`src/styles/*.css` o CSS de cada componente).
- **Componentes NG-ZORRO**: Usar siempre componentes oficiales de NG-ZORRO (`nz-layout`, `nz-card`, `nz-table`, `nz-form`, `nz-button`, etc.).
- **Colores**: Mantener los colores nativos de NG-ZORRO a menos que el usuario solicite explícitamente una personalización.
